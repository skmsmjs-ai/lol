BALANCE MODEL

왜 이 팀이 공정한가

이 매칭기는 “티어 합만 같으면 공정하다”는 가정을 쓰지 않습니다. 기준 티어에 실제 전적에서 학습한 선수별·역할별 보정을 더하고, 같은 역할끼리의 실력 차이와 바텀 2인 조합까지 함께 봅니다.

01전체 체급

두 팀의 티어 합이 크게 벌어지면 기본 벌점을 줍니다.

02역할 대칭

TOP·JG·MID의 맞상대 격차는 제곱으로 커지고, 1티어를 넘으면 추가 벌점이 붙습니다.

03바텀 상호보완

ADC·SUP는 개별 차이와 함께 2인 조합 지수를 별도로 계산합니다.

04실전 학습

K/D/A·CS와 선택 수치를 직접 입력해 통계 판정을 만들고, 승패와 함께 선수 추정치를 조금씩 갱신합니다.

1
역할군 격차 벌점

한 라인이 크게 터지는 조합을 막는 장치입니다.

Pr(d) = brsrd² + cr·max(0, d−1)²

d = 같은 역할 두 선수의 티어 차이

b = 기본 벌점, c = 1티어 초과 시 추가 벌점

s = 실제 경기 결과로 천천히 바뀌는 역할 영향도 보정값

TOP기본 11초과 38
JG기본 12초과 42
MID기본 11초과 38

정글만 초기값을 아주 조금 높게 두지만 “정글이 무조건 제일 중요하다”는 뜻은 아닙니다. Riot이 역할 숙련도 불일치, 특히 자동 선택 정글 대 주 포지션 정글을 별도로 문제로 다룬 점을 초기 prior에만 약하게 반영했습니다.

2
바텀 듀오 지수

원딜·서폿은 서로의 약점을 어느 정도 보완할 수 있다는 가정입니다.

B = 0.60·min(ADC, SUP) + 0.40·max(ADC, SUP)

티어 숫자가 낮을수록 강하므로 min은 더 잘하는 선수입니다. 예를 들어 2티어 + 6티어 바텀은 단순 평균 4.0이 아니라 3.6으로 봅니다. 다만 ADC와 SUP의 개별 격차 벌점도 따로 남겨 두므로 한 명의 강함이 모든 약점을 지워버리지는 않습니다.

3
경기 결과 수기 입력 · 통계 판정

OCR 대신 숫자를 직접 넣고 같은 포지션 두 선수만 비교합니다.

d(a,b) = (a − b) / (|a| + |b| + ε)
Sr = Σ wr,mdm / Σ wr,m

K/D/A와 CS는 필수, 피해량·골드·시야 점수는 선택입니다. KDA는 (K+A)/max(1,D)를 log(1+x)로 압축하고, 킬관여율은 10명의 킬 수에서 자동 계산합니다. 선택 수치가 비어 있으면 해당 항목만 제외하고 남은 가중치를 다시 100%로 정규화합니다.

TOPKDA 20KP 10CS 25피해 25골드 15시야 5
JGKDA 20KP 25CS 10피해 15골드 10시야 20
MIDKDA 20KP 15CS 20피해 25골드 15시야 5
ADCKDA 20KP 15CS 20피해 30골드 15시야 0
SUPKDA 20KP 30CS 0피해 10골드 5시야 35
|S| < 0.10 → 비슷→0.10~0.22 → 약우세→0.22~0.38 → 우세→0.38+ → 큰 우세

통계 판정을 그대로 쓰면 연속 점수로 보수적으로 학습하고, 사람이 A 우세·비슷·B 우세로 직접 바꾸면 그 판정을 더 강한 근거로 사용합니다. ‘제외’는 해당 포지션 학습만 건너뜁니다. 이 점수는 라인전만이 아니라 경기 전체의 포지션별 성과 지표입니다.

4
실제 내전 학습

팀 승패와 포지션 성과를 서로 다른 통로로 학습합니다.

p(A) = sigmoid(wTxT + wJxJ + wMxM + wBxB)
A/B 승리→전체 실력 보정+수기 경기 수치→역할별 실력 보정

한두 판 때문에 추정치가 급변하지 않도록 경기 수가 늘수록 변화폭을 줄입니다. 통계 자동판정의 학습 강도는 수치 완성도에 따라 약 35~65%로 제한하고, 직접 수정한 판정도 90% 강도로 제한합니다.

5
선수 티어 자동 보정

사람이 정한 기준 티어는 보존하고, 실제 경기에서 별도의 추정값만 움직입니다.

T추정 = T기준 − R전체
T역할 = T추정 − R역할

숫자가 낮을수록 강합니다. 팀 승패는 전체 보정값에, 같은 역할의 실제 우세는 역할별 보정값에 반영합니다. 예를 들어 기준 3티어 선수가 미드에서 반복해서 더 높은 티어 선수를 앞서면 ‘전체 추정 2.8 / MID 역할 추정 2.5’처럼 변할 수 있습니다. 기준 티어 자체는 사용자가 수정하기 전까지 바뀌지 않습니다.

  • Riot 2026: 가능하면 자동 선택된 선수를 상대 팀의 같은 포지션 자동 선택 선수와 맞추도록 개선했습니다.
Riot 2022 역할군 공평성 ↗ Riot 2024 대전 검색 ↗ Riot 2026 자동 선택 공평성 ↗
