내전 자동 매칭기 — PWA v5
===========================

핵심 변경
- 사진/OCR 기능 없음
- 경기 후 10명의 K/D/A와 CS를 직접 입력
- 피해량, 골드, 시야 점수는 선택 입력
- 같은 포지션 A/B 선수의 수치를 역할별 가중치로 비교해 통계 판정 자동 생성
- 통계 판정을 그대로 사용하거나 A 우세/비슷/B 우세/제외로 직접 수정 가능
- 지난 전적도 동일한 수치 입력 방식 지원
- v4의 선수 상세, 승률, 포지션별 전적, 추정 티어 변화 그래프 유지

필수 입력: 승리팀, 10명 K/D/A, 10명 CS
선택 입력: 경기시간, 피해량, 골드, 시야 점수

역할별 가중치(%)
TOP KDA20 KP10 CS25 피해25 골드15 시야5
JG  KDA20 KP25 CS10 피해15 골드10 시야20
MID KDA20 KP15 CS20 피해25 골드15 시야5
ADC KDA20 KP15 CS20 피해30 골드15 시야0
SUP KDA20 KP30 CS0  피해10 골드5  시야35

선택 수치가 비어 있으면 그 항목만 제외하고 남은 가중치를 다시 정규화합니다.
같은 URL에서 v4→v5로 교체하면 기존 localStorage 데이터는 이어받습니다.
