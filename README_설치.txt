내전 자동 매칭기 — PWA v6

공유 주소: https://skmsmjs-ai.github.io/lol/

공유받은 4자리 비밀번호로 입장합니다. Mac, iPhone, iPad에서 같은 서버 자료를 사용합니다.
경기 입력은 레벨, K/D/A, CS, 게임 시간, 획득 골드입니다. 게임 시간은 경기당 한 번 입력합니다. 시야 점수와 피해량은 새 입력에 사용하지 않습니다. 승리팀은 생략할 수 있습니다.

기존 iPhone 기록은 해당 기기의 브라우저에 있습니다. 먼저 백업을 내보내고 관리자에서 기존 자료를 가져옵니다. 서버에 다른 경기 기록이 있으면 덮어쓰지 않고 중단합니다. 원본 백업을 보관하세요.

관리자는 별도 계정으로 로그인해 입장 번호/관리자 비밀번호 변경, 참가자 입장 중단, 기존 자료 가져오기와 초기화 등을 할 수 있습니다. 관리자 로그인 정보는 참가자에게 공유하지 않습니다.

새 화면이 보이지 않으면 기존 링크를 새로고침하거나 설치한 앱을 닫고 다시 엽니다. 브라우저 자료를 삭제하기 전에 기존 경기 기록을 백업하세요.

자세한 계산 규칙과 확인 범위는 전체 소스 묶음의 README.md와 변경_확인.md에서 확인합니다.
