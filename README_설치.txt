내전 자동 매칭기 — PWA v2
===========================

1. 이번 버전의 핵심
-------------------
- iPhone 홈 화면에서 앱처럼 실행하는 PWA
- 기존 멤버/티어/포지션/경기 학습 데이터 자동 저장
- 2~5명짜리 같은 팀 고정 그룹 지원
- 서로 다른 황금밸런스 후보 최대 3개
- 2·3안은 가능하면 1안과 팀당 최소 2명 이상 다른 구성
- 미니멀한 다크 네이비 + 골드 UI로 전면 개편
- 하단 '기준' 탭에 밸런스 수식, 현재 가중치, 근거, 한계, Riot 공식 자료 링크 추가

2. 밸런스 엔진
--------------
낮은 티어 숫자 = 강한 선수입니다.

(1) 팀 전체 체급
- 두 팀의 티어 합 차이에 제곱 벌점

(2) TOP / JG / MID 역할 대칭
- 같은 역할의 티어 차이에 제곱 벌점
- 1티어 차이를 넘으면 추가 벌점이 비선형으로 커짐
- 정글의 초기 prior만 아주 약간 높지만, 실제 내전 결과로 역할 영향도가 천천히 변함

(3) BOT
- ADC/SUP 개별 차이도 계산
- 동시에 더 잘하는 사람 60%, 약한 사람 40%의 듀오 지수를 만들어 상호보완을 반영

(4) 실전 학습
- 사용한 안 1/2/3 + 승리팀 A/B만 입력
- TOP/JG/MID/BOT 영향도가 작은 학습률로 갱신됨
- 한 경기의 우연 때문에 모델이 흔들리지 않도록 초기값으로 돌아가려는 규제를 둠

주의: Riot은 공식 대전 검색의 정확한 역할별 계수나 공식을 공개하지 않습니다.
앱의 세부 숫자는 Riot 공식 수치가 아니라, 역할군 공평성이라는 공개 원칙과 내전 사용 목적을 바탕으로 만든 투명한 휴리스틱입니다.

4. 설치
-------
GitHub Pages, Cloudflare Pages, Netlify 같은 HTTPS 정적 호스팅에 이 폴더의 파일을 그대로 올립니다.

아이폰 Safari에서 주소 접속
→ 공유
→ 홈 화면에 추가
→ 웹 앱으로 열기
→ 추가

같은 URL을 계속 사용하면 같은 로컬 저장공간을 사용합니다.

5. 데이터
---------
평소에는 iPhone 브라우저 로컬 저장공간에 자동 저장됩니다.
'기록' 탭의 백업 내보내기로 JSON 파일을 가끔 iCloud Drive 등에 보관하면 됩니다.
